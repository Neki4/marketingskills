# AtticCraft Dublin: новая версия сайта

Новая версия сайта [atticcraftdublin.ie](https://atticcraftdublin.ie/). Перенесены все страницы, разделы, тексты, фото, видео, контакты, форма заявки и аналитика. Дизайн и вёрстка новые.

## Структура

```
atticcraft-dublin/
├── index.html                 # Главная (все разделы старой главной)
├── blog/
│   ├── index.html             # НОВОЕ: список всех статей
│   └── *.html                 # 8 статей; имена файлов те же, что на старом сайте
├── 404.html                   # Страница «не найдено»
├── assets/css/style.css       # Общие стили
├── assets/js/main.js          # Меню, cookie-баннер, форма, анимации
├── img/  video/               # Медиа с оригинального сайта (те же пути)
├── sitemap.xml  robots.txt
```

## Что улучшено

- **SEO:** в статьях были неправильные `canonical` (без `.html` и с несуществующими адресами). Исправлено. Добавлена разметка BlogPosting и BreadcrumbList.
- **Аналитика:** в статьях блога не было Google Analytics и Ads. Теперь тег есть на всех страницах. Добавлены события `generate_lead`, `whatsapp_click` и `phone_click`.
- **GDPR:** Google Consent Mode v2. До нажатия Accept cookie аналитики не ставятся (раньше ставились сразу).
- **Форма:** честный статус отправки (раньше «успех» показывался в любом случае) и защита от спама (honeypot).
- **Мобильная версия:** нижняя панель WhatsApp и Book Now, удобное меню.
- В подвале исправлены пустые ссылки в «Services».

## Публикация

Сайт статический, сборка не нужна. Достаточно загрузить содержимое папки в корень хостинга (LiteSpeed/cPanel) с заменой старых файлов. Адреса статей сохранены, поэтому позиции в Google не пострадают.

Локальный просмотр:

```bash
cd sites/atticcraft-dublin && python3 -m http.server 8000
```
